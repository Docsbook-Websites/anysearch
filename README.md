# AnySearch Documentation

AnySearch is the search infrastructure your AI agent can trust: one API that understands intent, filters noise, and routes queries to the right data source across finance, code, academia, security, business, health, travel, and more.

Every response comes back structured and ready for an agent to use — no scraping, no parsing, no guesswork about which source to query.
